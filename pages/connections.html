About Platform APIs

Instagram / Facebook

Requires Meta Business Suite and an approved app with publish permissions. Videos must be under 60 seconds for Reels.

Developer Portal →

TikTok

Uses TikTok for Developers API. Requires app approval for content posting. Videos up to 10 minutes supported.

Developer Portal →

YouTube

Uses YouTube Data API v3. Requires OAuth 2.0 consent. Daily quota limits apply (10,000 units/day default).

Google Cloud Console →

Threads

Uses Meta's Threads API. Shares the same Meta App as Instagram/Facebook. Supports text and video posts up to 5 minutes.

Developer Portal →

Twitter/X

Requires Twitter API v2 with elevated access for media uploads. Free tier limited to 500k tweets/month.

Developer Portal →

Connect Platform

To connect your platform account, you'll need to provide API credentials from the platform's developer portal.

Some platforms require OAuth flow instead. Leave blank if not available.
Credentials are stored locally and encrypted. They're never sent to our servers.
