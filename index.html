How Image Generation Works

1. Story Anchor: AI analyzes your story to create a "visual bible" - consistent environment, colors, and mood.

2. Art Style Applied: Your selected style (e.g., "Analog Horror") defines the aesthetic - VHS grain, colors, lighting.

3. Visual Beats: Each scene gets camera angles and mood levels that escalate tension.

4. AI Generation: Images created using: Art Style + Story Anchor + Scene Beat (FLUX uses Scene 1 as reference)

🎨 Art Style Editor

📖 How Art Styles Work in Image Generation

Each art style has 4 key components that get injected into the AI image prompt:

Base Prompt:

The main style description. Sets the overall look (e.g., "VHS static, glitch artifacts, scanlines").

Color Override:

Color palette to use (e.g., "washed out colors, muted greens and grays").

Technical Style:

Keywords for the rendering method (e.g., "lo-fi horror, found footage").

Negative Prompt:

What to avoid (e.g., "bright colors, clean, professional").
